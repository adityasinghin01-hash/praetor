PRAETOR — an accounts-payable agent that cannot be hijacked by the document it is reading

The model handles references, never values. Every consequential decision is made by deterministic code that no prompt can reach — so a fully compromised reader still cannot change what gets paid. Measured: the agent was talked into the wrong answer twice, and was overruled both times.

Vendor master — derived, not invented
eval/build_vendor_master.py
Each supplier’s “normal” is the modal value across their own past invoices — known accounts, usual currency, tax rate, address, amount range. Feeds the rules, the gate and the agent. Exceptions are discovered, never injected.
Cost guard — a ceiling, not an estimate
praetor/costguard.py
Prices every call against Google’s published rates and raises BudgetExceeded before the call that would cross the ceiling. Persisted to disk, so it holds across runs and across days.
Provenance you can audit later
praetor/trace.py · OpenTelemetry
Every span carries the taint label, the document hash and the span id of the value it touched. That is how you answer, months after the fact, whether a paid figure came off a document nobody trusted. Exports to a file today; Cloud Trace is one exporter away.
Tenancy — why the fleet cannot merge
praetor/tenancy.py
One AP processor runs many client companies. A supplier’s “known account” only means anything inside one client’s books, so the lookup is scoped and a cross‑tenant pairing raises rather than decides. test_tenancy.py demonstrates the bug that merging them reintroduces.

Measured, not claimed

Every figure below is reproducible from this repository — see FINDINGS.md. Nothing here is an industry estimate.

60%
undefended attack rate
12 of 20 injection techniques beat a plain extraction prompt. Every one that worked reads like ordinary business correspondence. The kernel that stops them runs at ~4,100 documents/second on one core — 7,300× faster than the model it protects.
0.874
rules baseline F1
Recall 0.963, right reason on 100% of catches. Extraction on the live path is F1 1.000 with Gemini and 0.384 with a 1b Gemma — neither could introduce a value.
28%
fewer human touches
65 → 47 on 350 invoices at 1.000 precision — zero wrong resolutions, taking the run from 81.4% autonomous to 86.6%.
2
gate overrides
A fake remittance notice and a fabricated approval ticket each convinced the agent to resolve. Deterministic code refused both. Fooled twice, correct twice.
